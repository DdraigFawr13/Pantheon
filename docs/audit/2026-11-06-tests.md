## Other findings

### F1 The play-guard test can be skipped and covers only part of the hook

- **Rework if left:** medium
- **Effort:** M
- **Evidence:** `tests/test_session.py:240` "env = {"CLAUDE_PROJECT_DIR": str(tmp_path), "PATH": "/usr/bin:/bin:/usr/local/bin"}"
- **Case:** The test has four weaknesses:
  - It is `skipif` node is missing, so CI could go green with NAR-02's only guard untested.
  - The hard-coded POSIX `PATH` breaks where node lives elsewhere, such as nvm or Windows (D-021).
  - It has no case for Edit, Glob, Agent, MCP tools, `..` in a Write path, or a chained `cd` command. That last case is the bypass in repo F1.
  - It matches the substring `"deny"` instead of parsing the decision.
- **Fix:**
  - Fail instead of skip when `CI` is set.
  - Copy `os.environ` instead of hard-coding `PATH`.
  - Add table cases, including the repo F1 probe and an MCP tool name.
  - Parse the JSON decision.

### F2 The import-boundary test misses three import forms and has no negative case

- **Rework if left:** medium
- **Effort:** S
- **Evidence:** `tests/test_import_boundary.py:17` "elif isinstance(node, ast.ImportFrom) and node.module:"
- **Case:** Three forms slip past it:
  - `from pantheon import ui` has module `pantheon` and passes.
  - `from ..ui import x` has module `ui` and passes.
  - `importlib.import_module` is not an import node at all.

  The engine could cross the SPEC section 4 boundary while the test stays green, and nothing proves the test can fail.
- **Fix:** Resolve relative modules from `level`, and check `module.alias` for each name. Flag `import_module` and `__import__` calls. Add a test that feeds the scanner a bad snippet.

### F3 Hypothesis runs unpinned, and two properties use the 200 ms default deadline

- **Rework if left:** medium
- **Effort:** S
- **Evidence:** `tests/engine` absent: searched "register_profile", "derandomize", "load_profile" in tests/ and pyproject.toml

A new counterexample can turn CI red on an unrelated commit and is not reproducible from the commit (VER-04, GAME-01's intent). The two properties in `tests/engine/test_checks.py` (lines 28 and 295) have no `@settings`, so a slow runner can trip the deadline.
- **Fix:** Add a `tests/conftest.py` profile with `derandomize=True` and `deadline=None`, loaded by default.
